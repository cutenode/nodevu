# @nodevu/core

The core, online-only module of nodevu. It fetches the version information Node.js publishes and merges it into one object keyed by release line, with each line's phase, its newest and oldest LTS and security releases, and the files each release ships.

```bash
npm install @nodevu/core
```

Usage and the full API are in the [docs](https://cutenode.github.io/nodevu/core).
