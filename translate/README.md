# @nodevu/translate

Translates the terms of the Node.js Package Maintenance working group's [package support document](https://github.com/nodejs/package-maintenance/blob/main/docs/PACKAGE-SUPPORT.md) to the aliases `@nodevu/ranges` takes. Not published to npm yet.

Usage and the full API are in the [docs](https://cutenode.github.io/nodevu/translate).
