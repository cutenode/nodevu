# @nodevu/parsefiles

Parses an identifier from the `files` of a release in the [Node.js release index](https://nodejs.org/dist/index.json), such as `linux-x64`, into the file names it stands for, its platform, and its architecture.

```bash
npm install @nodevu/parsefiles
```

Usage and the full API are in the [docs](https://cutenode.github.io/nodevu/parsefiles).
